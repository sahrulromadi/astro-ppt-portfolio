## 1. Overview mode

Seperti Slide Sorter di PowerPoint: semua slide tampil sebagai grid thumbnail.

- Buka: tekan `O` atau tombol grid di bar navigasi.
- Pilih slide: klik thumbnail, atau Tab ke thumbnail lalu Enter/Spasi → kembali ke mode slide di slide itu.
- Tutup tanpa pindah: `Esc` atau `O` lagi → kembali ke slide sebelumnya.
- Cara kerja: class `overview` di `<html>` mengubah deck dari baris horizontal jadi grid; tiap slide dikecilkan dengan CSS `zoom` (skala dihitung JS dari lebar layar: 4 kolom ≥ 1200 px, 3 kolom ≥ 700 px, selain itu 2).
- Selama overview: isi slide di-`inert` (link di dalam thumbnail tidak bisa diklik/difokus); thumbnail sendiri bisa difokus (`tabindex=0`, `role=button`). Observer slide aktif dan wheel handler berhenti sementara.

## 2. Tracking (IP, user agent, waktu buka) — Supabase

## Database — sudah disiapkan (2026-10-14 19:16 WIB)

Project Supabase di region Tokyo (`ap-northeast-1`). Host direct `db.<ref>.supabase.co` hanya IPv6 dan tidak terjangkau dari jaringan lokal, jadi `.env` memakai **Session Pooler** (IPv4) di `POSTGRES_URL`. `.env` juga dirapikan ke format `NAMA=nilai`.

```sql
create table public.portfolio_visits (
  id bigint generated always as identity primary key,
  visited_at timestamptz not null default now(),
  ip_address text not null,
  user_agent text not null
);
alter table public.portfolio_visits enable row level security;
grant insert on public.portfolio_visits to service_role;
```

Dicek langsung ke database: secret key insert → 201, `visited_at` terisi otomatis, publishable key insert → 401, publishable key baca → 0 baris. Baris uji dihapus, `id` direset ke 1; tabel kosong.

## Butuh dari pemilik (setelah deploy)

1. Vercel → proyek → **Settings → Environment Variables**: isi `SUPABASE_URL` dan `SUPABASE_SECRET_KEY` (sama dengan `.env` lokal; `.env` tidak ikut ter-deploy).
2. Redeploy, buka situs dari HP, lalu cek di SQL Editor Supabase:

   ```sql
   select visited_at at time zone 'Asia/Jakarta' as waktu, ip_address, user_agent
   from portfolio_visits
   order by visited_at desc
   limit 100;
   ```
